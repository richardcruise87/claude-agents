## Step 2: Find and fetch the original upstream change

Extract the original Change-Id or commit SHA from the commit message:
```bash
git log -1 --format=%B | grep -E "(Original-Change-Id|cherry picked from)"
```

Fetch the original upstream change:
```bash
ORIG_CHANGE_ID=$(git log -1 --format=%B | grep "Original-Change-Id:" | awk '{print $2}')
if [ -n "$ORIG_CHANGE_ID" ]; then
    # Look up the change number from the Change-Id
    curl -s "{gerrit_base_url}/changes/?q=change:$ORIG_CHANGE_ID+project:{repo_name}&o=CURRENT_REVISION" \
        | tail -c +5 | python3 -c "
import json,sys
data = json.load(sys.stdin)
if data:
    d = data[0]
    rev = d.get('current_revision','')
    ref = d.get('revisions',{}).get(rev,{}).get('ref','')
    print('Change number:', d.get('_number'))
    print('Fetch ref:', ref)
"
fi
```

If you can determine the upstream fetch ref, fetch and compare:
```bash
git fetch {gerrit_base_url}/{repo_name} <upstream_fetch_ref>
UPSTREAM_SHA=$(git rev-parse FETCH_HEAD)

# Compare the diffs
git diff $UPSTREAM_SHA^..$UPSTREAM_SHA > /tmp/upstream.diff
git diff HEAD^..HEAD > /tmp/backport.diff
diff /tmp/upstream.diff /tmp/backport.diff || true
```

## Step 3: Check the Backport-Candidate label on the original

```bash
if data:

    print('All labels:', json.dumps({k: list(v.keys()) for k,v in labels.items()}, indent=2))
"
fi
```
