**What to look for:**
1. **Test failures** — FAIL, ERROR, AssertionError, specific test names
2. **Timeout** — "timed out", "Connection timed out", "deadline exceeded"
3. **Network/package issues** — pip install failures, mirror errors, DNS
4. **Resource issues** — No space left, OOM, Killed
5. **Node/infra issues** — "lost connection", "node was lost", "post-failure"
6. **Import/dependency errors** — ImportError, ModuleNotFoundError
7. **Build setup failures** — failures before tests run

### Step 2: Classify Each Failure

Assign exactly ONE category to each job:

**CODE_ISSUE** — The failure is caused by a bug directly introduced by this patchset.

**ENVIRONMENTAL** — Infrastructure or intermittent issue; re-running will likely succeed.
- Network timeouts, package mirror unavailability, cloud resource exhaustion
- Timeouts in setup, known flaky tests

**UNRELATED** — Pre-existing failure independent of this change.

**INFRA_FAILURE** — Zuul/CI infrastructure failure; no code change can fix this.
- "lost connection to worker", "post-failure", node pool exhaustion
